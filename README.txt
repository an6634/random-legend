IMPORTANT
Service workers and installable PWA behavior require HTTPS (or localhost).
Opening index.html directly from Files/Downloads will still run the generator,
but offline installation behavior will not activate until the folder is hosted.

IPHONE INSTALL
1. Host this folder on an HTTPS static host.
2. Open the hosted URL in Safari on iPhone.
3. Tap Share.
4. Tap Add to Home Screen.
5. Launch Random Legend from the Home Screen.

Your enabled Legend pool and recent roll history stay local to that device.
